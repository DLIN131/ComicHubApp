# ComicHub（手機版）

ComicHub 桌面版的 Android 手機版：把四個漫畫站整合成一個 App。四個站在程式裡以 NH / JM / WN / EH 代稱。

## 下載

最新版：https://github.com/DLIN131/ComicHubApp/releases/latest/download/ComicHub.apk

需要 Android 8 以上。之後有新版會在 App 裡提示，按「立即更新」就會下載並安裝。

## 功能

- 首頁：四站最新更新，或切到單一站依排序瀏覽（往下捲自動載入）
- 搜尋：一次搜勾選的站，結果交錯排列，每張封面標示來源網站；上方可只看某一站
- 編號搜尋：純數字會用這個編號查每個勾選的站；加上站別前綴（例如 `JM123456`、`#123456`）只查該站；直接貼作品網址也可以（EH 只能用網址）
- 語言：「全部語言／中文／English／日本語」切換，首頁、搜尋、收藏、紀錄、書櫃都會跟著篩，封面右上角標示語言
- 作品頁：標籤點了會在該站搜尋；多話作品有章節列表；「用此漫畫搜尋」可用書名、原文書名或作者到所有站找同一本
- 閱讀：上下捲動或左右翻頁（可設定由右往左），雙指縮放、雙擊放大，拖曳下方進度條跳頁；多話作品看完直接接下一話；被切條打亂的圖片會自動重組
- 閱讀進度：自動記住每本看到第幾話、第幾頁，作品頁、書櫃有「繼續閱讀」，紀錄頁顯示看到哪
- 下載：作品頁按「下載 CBZ」（多話作品可下載全部或單話），在背景下載並在通知列顯示進度，可暫停、繼續；CBZ 內附 ComicInfo.xml，檔名格式跟桌面版一樣，兩邊的檔案可以互相搬
- 書櫃（離線閱讀）：下載的漫畫不用網路就能看；可分組、點作者名搜尋相關作品、用書名搜尋、分享、刪除；按 ＋ 可加入手機裡其他的 CBZ / ZIP（也可以從檔案管理員用 ComicHub 開啟）。「合集」可以把幾本串成一本連續看，閱讀時可跳到每本的第一頁，可調整順序、選封面
- 收藏：作品頁按 ♡ 收藏，四個站都可以收、不用登入，在「收藏」頁的「本機收藏」看（長按取消）；旁邊的各站分頁是登入後的網站帳號收藏
- 帳號：每個站各自登入（開該站自己的登入頁，帳密不經過本 App），登入後可看網站收藏；NH 可以在作品頁直接加入 / 移除網站收藏
- 網站換網域時，在「帳號」頁改網址即可
- 圖片快取上限 150 MB，看越多也不會一直吃空間

書櫃的漫畫存在 App 自己的資料夾（Android/data/com.comichub.app/files/downloads），解除安裝時會一起刪除；要保留可以先用書櫃的「分享」存到別的地方。

## 開發

用 Android Studio 開啟，或：

```
./gradlew assembleRelease
```

推到 main 會由 GitHub Actions 自動打包並發布 `v1.0.<build 號>`。解析器的單元測試需要網頁存檔（不放在 repo 裡），設定環境變數 `FIXTURES` 指到存檔資料夾才會跑。
